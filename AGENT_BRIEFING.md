# AI Agent Project Briefing: Enhanced SCR

## 1. Project Background and Origin
This project originated as a fork of a MATLAB-based autonomous racing simulator implementing **Sequential Convex Restriction (SCR)** (based on Liniger et al.). The original simulator models a 1:43 scale RC car driving on a miniature track (Hockenheim Short, ~25m length).
The baseline SCR algorithm uses Model Predictive Control (MPC) with a Sequential Convex Programming (SCP) solver (quadprog) to optimize the car's racing line.

## 2. Current State: Enhanced SCR v1
The baseline SCR solver achieved a lap time of **10.00s**, severely bottlenecked by a static terminal velocity constraint ( = 0$ at the end of the 40-step prediction horizon). This forced the car to "phantom brake" on straightaways. 

However, simply removing this terminal constraint caused the solver to command aggressive steering at high speeds. The resulting massive slip angles broke the local linearizations of the SCP solver, causing the mathematical predictions to diverge from the non-linear physics and resulting in a solver crash (exitflag -2: infeasible).

We successfully extended the algorithm to create **Enhanced SCR v1**, breaking the 10-second barrier to achieve a **9.40s** lap time (a 6% improvement). 

### The Mathematical Breakthroughs:
1. **Intelligent Physical Lookahead Radar:** We replaced the static terminal constraint with a dynamic radar that scans 80 checkpoints ahead. It calculates the absolute maximum safe cornering speed using lateral acceleration physics ({safe} = \sqrt{\mu g / \kappa}$), clamping the terminal speed only when approaching sharp turns.
2. **Double-Resolution SCP:** Increased SCP_iterations to 2, allowing the Real-Time Iteration (RTI) solver to accurately resolve the highly non-linear sideslip dynamics generated by high-speed cornering.
3. **Linearization-Stabilizing Cost Damping:** We increased the steering penalty in the control cost matrix (R = diag([100.0, 15.0])). This mathematically forces the car into smoother racing lines, preventing the extreme slip angles that cause linearization divergence.

## 3. Future Goals & Objectives
The project is now splitting into two parallel tracks:

### Track A: 1:1 Scale Assetto Corsa Implementation (The Ultimate Goal)
We are translating the Enhanced SCR algorithm into **C++** to run as an autonomous controller in the hyper-realistic racing simulator **Assetto Corsa**. 
* **Challenges to solve in C++:**
  * **Physics Scaling:** Upgrading the Single-Track model to include aerodynamic downforce (which increases tire grip at high speeds) and weight transfer (pitch/roll).
  * **Real-Time Performance:** Swapping MATLAB's quadprog for a high-performance C++ solver (e.g., cados, OSQP, HPMPC) capable of solving at Assetto Corsa's 333Hz physics tick rate.
  * **Actuator Mapping:** Creating a low-level PID controller to map the MPC's raw acceleration/steering commands into human-like Gas, Brake, and Steering Wheel inputs.
  * **Telemetry:** Interfacing with Assetto Corsa's shared memory API to extract real-time state estimation (position, velocity, slip angles).

### Track B: Continued 1:43 Scale Refinement
We will continue to refine the MATLAB codebase to see if we can push the 1:43 scale miniature car even faster than 9.40s.
